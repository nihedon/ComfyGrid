**注）現在はベータ版です。予期せぬ不具合や仕様変更が発生する可能性があります。**

ComfyGridは、ComfyUIのワークフローを操作しやすい画面に整理するアプリケーションです。Stable Diffusion WebUIを参考にした画面で、よく使うノードやウィジェットを配置し、ノードグラフを毎回たどらずに入力調整や画像生成を行えます。

ワークフローの作成・接続は、あらかじめComfyUIで行ってください。ComfyGridは既存のワークフローの操作を補助するものであり、ワークフローの構築や必要なカスタムノード・モデルの導入を代行するものではありません。

## 主な機能

- ノードをリサイズ可能なGridStackボードに自由配置、または通常のグループレイアウトで表示
- 内蔵ComfyUIの直接操作と、ComfyUIで開いているワークフローの切り替え
- 通常のテキスト、CodeMirrorによるプロンプト・JSON編集、Ollama翻訳、任意で有効にできるPromptPilotのタグ補完
- モデルのサムネイル・詳細表示、ワークフローファイル管理、画像メタ情報の確認
- 生成進捗・結果の表示、画像・マスク編集、メタ情報を含む画像保存
- カラーピッカー、バウンディングボックス、Camera Angle、Load 3D、解像度プレビュー、テキストプレビューのMarkdown表示などへの対応

## 動作環境

- **OS:** Windows。macOS向けのリリースには現在対応していません。
- **ブラウザ:** Google Chrome、Microsoft EdgeなどのChromium系ブラウザ
- **ComfyUI:** 正常に動作するComfyUI Portable環境。**動作確認バージョンはComfyUI v0.42.0**です。他のすべてのバージョンとの互換性を保証するものではありません。
- **Ollama:** 翻訳機能を使用する場合のみ必要です。

## 導入と初回設定

### ダウンロードと起動

1. [Releasesページ](https://github.com/nihedon/ComfyGrid/releases)から`ComfyGrid-portable-x.x.x.zip`をダウンロードします。
2. 書き込み可能なフォルダに展開します。
3. 展開したフォルダ内の`run.bat`を実行します。
4. ブラウザで`http://127.0.0.1:6210/comfygrid/`を開きます。

通常はポータブル版をご利用ください。`frontend-dist-x.x.x.zip`は、自分でPython環境を用意し、リポジトリのソースから実行する方向けのビルド済みフロントエンドです。ポータブル版一式ではありません。以前の単独実行ファイル（exe）版の配布は終了しています。

### プロファイルの作成

![セットアップ画面のプロファイル設定例](https://github.com/user-attachments/assets/3960736f-be97-4dfc-96c7-cfb454cb4c31)

画像内のプロファイル名とパスはサンプルです。自分のComfyUI環境に合わせて指定してください。

1. セットアップ画面の **+ New Profile** を選び、名前を入力します。
2. **ComfyUI main.py**に、起動したいComfyUIの`main.py`を指定します。
3. **Python実行ファイル**に、そのComfyUIで使用しているPythonを指定します。
4. 必要に応じてComfyUIのポートや起動引数を設定します。
5. プロファイルを保存し、そのプロファイルでComfyUIを起動します。保存だけではComfyUIは起動しません。

ComfyUI Portableのパス例:

```text
ComfyUI main.py: D:\ComfyUI_windows\ComfyUI\main.py
Python:         D:\ComfyUI_windows\python_embeded\python.exe
```

### プロファイルの管理

異なるComfyUI環境や起動設定を、複数のプロファイルとして保存できます。一覧のプロファイルを選び、右側の「…」ボタンから操作します。

- **名前を変更:** プロファイル名を編集します。
- **複製:** 現在の設定を基に、別のプロファイルを作成します。
- **削除:** プロファイルの登録を削除します。ComfyUI本体のファイルは削除されません。起動中のプロファイルは停止してから削除してください。

グローバルメニューからセットアップ画面に戻ることもできます。

## 画面構成

| タブ       | 役割                                               |
| ---------- | -------------------------------------------------- |
| Grid       | ワークフローの入力調整、ノード配置、生成結果の表示 |
| ComfyUI    | 内蔵されたComfyUIのノードグラフを直接操作          |
| Files      | 保存済みワークフローの管理、モデル詳細の閲覧       |
| Image Info | 画像のメタ情報や生成情報を確認                     |
| Settings   | 外観、保存、Ollama、PromptPilotなどを設定          |

ヘッダーにはグローバルメニュー、開いているワークフローの選択、生成操作、進捗表示があります。設定に応じて、ComfyUIのトップレベルのグループをGrid内のタブとして表示できます。

## 基本操作

### ワークフローの読み込みと生成

1. **ComfyUI**タブで動作するワークフローを読み込むか作成します。**Files → Workflows**から保存済みワークフローを開くこともできます。
2. **Grid**に切り替え、必要なノードの入力値を調整します。
3. 生成操作ボタン、または**Ctrl+Enter**で生成をキューに追加します。
4. 進捗と、ギャラリーに表示される結果を確認します。

ワークフローJSONやワークフローを含む画像をヘッダーにドロップして読み込むこともできます。テキスト入力欄以外でJSON・外部URL・画像を貼り付けると、確認後にワークフローの読み込みを試みます。ワークフロー情報を含まない画像からは復元できません。

### ノードの配置

ノードをGridStackボードに移動すると、通常のグループ内の並びから切り離して配置できます。

1. ノードヘッダー右端の移動ボタンを押します。
2. 「グローバル空間」または「タブ空間」を選びます。タイトル部分の右クリックからも移動できます。

![ノードヘッダーのボタンからGridStackへの移動先を選択](https://github.com/user-attachments/assets/6bd5454b-71f0-4b28-94bc-45c9f8060b58)

- **グローバル空間:** グループタブの上にあるGridStackボード。Grid内のタブを切り替えても表示されるため、共通して操作したいノードを置く場所です。
- **タブ空間:** 対象グループのタブ内部にあるGridStackボード。そのタブで操作するノードを置く場所です。
- **タブに収める:** GridStackから外し、通常のグループレイアウトに戻す操作

![グローバル空間・タブ空間・通常配置の位置関係](https://github.com/user-attachments/assets/54dc6387-f8e8-4fa3-a74d-898881edab43)

上の例では、タブより上の「共通の生成設定」がグローバル空間、「基本生成」タブ内の「画像サイズ」がタブ空間、その下の「サンプリング設定」が通常配置です。「高解像度」タブに切り替えると「基本生成」タブの内容は切り替わりますが、「共通の生成設定」は表示されたままになります。画像はモデルや生成結果を含まないサンプルです。

GridStack上では、ノードのヘッダーをドラッグして位置を変え、リサイズハンドルで大きさを変更できます。タブ空間へ移動したときやタブに収めたときは、移動先タブがアクティブになります。各タブのボードを共通化している場合、移動先はNodesタブです。

Customtextと他のウィジェットを含むノードでは、Customtext部分だけを独立して移動することもできます。その移動操作は、ComfyUIのノード全体ではなく対象ウィジェットだけに適用されます。

DOMウィジェットを含むノードをGridStackに置くと、ヘッダーにコンテンツをノード内に収めるトグルが表示されます。初期状態はOFFです。ONにすると利用可能なサイズに合わせますが、極端に小さいノードには操作欄すべてが収まらない場合があります。

### ノードと入力欄の操作

- ノード・グループのモードを通常・ミュート・バイパスに変更できます。Settingsからノードモードの簡略表示も選べます。
- ノードタイトルのダブルクリックで名前を変更し、タイトル部分の右クリックで複製・折りたたみ・削除などを操作できます。
- 詳細入力を持つノードでは、詳細項目の表示を切り替えられます。
- 対応する数値欄はドラッグで調整でき、クリックすると全選択された編集状態になります。**Shift**で細かく、**Ctrl**で速く調整できます。
- 数値の`width`と`height`が隣接している場合、間に表示される入れ替えアイコンで値を交換できます。

ノードの変更・削除は、ComfyGrid上の見た目だけでなく、元のComfyUIワークフローにも反映されます。

### テキスト種別の選択

| 種別       | エディタ                               | Tags                           |
| ---------- | -------------------------------------- | ------------------------------ |
| テキスト   | 通常のtextarea                         | 非表示                         |
| プロンプト | CodeMirror                             | 表示。プロンプト選択時は初期ON |
| JSON       | JSON編集・自動整形に対応したCodeMirror | 表示。初期OFF                  |
| Ollama     | 翻訳原文を入力するCodeMirror           | 非表示                         |

![プロンプトとJSONのエディタ、およびTagsのON・OFF表示](https://github.com/user-attachments/assets/53a9ed17-c3e8-40ff-bdab-1e560b671f54)

上段は「プロンプト」でTagsがON（色付きのTagアイコン）、下段は「JSON」でTagsがOFFの表示例です。エディタの種類は左側の種別名から選び、タグ補完を使うかどうかは隣のTagアイコンで別に切り替えます。JSONでもTagsをONにできます。

**Tagアイコン**で、プロンプト・JSONのエディタ種別とは別にPromptPilotの補完を切り替えられます。補完はグローバルのPromptPilot有効設定にも従います。TagsがONならプロンプトの色付け設定に従い、OFFなら句読点や改行で区切った単位でCodeMirrorの文字を色分けします。

Ollamaでは接続先URL、モデル、システムプロンプト、翻訳タイミング、固定・ランダムの翻訳シードを設定できます。対応する設定はウィジェットごとにグローバル設定を上書きできます。原文と翻訳結果は別々に保持します。

### モデルの閲覧と選択

使用モデルの変更は、ノード内のモデル選択欄から行います。対応する選択欄ではサムネイルやモデル情報を確認できます。

**Files**のModels・LoRAs・Embeddings・Hypernetworksでカードをクリックすると、モデル詳細を表示します。これらのカードから直接モデルを適用したり、プロンプトに文字列を挿入したりする動作ではありません。モデルファイルを追加した場合は一覧を更新してください。

### 画像の情報を確認する

**Image Info**に画像を読み込むか、ギャラリーの情報ボタンから送信すると、画像と埋め込まれたメタ情報を確認できます。JSONの項目を展開して生成時の入力を確認でき、対応するワークフロー情報があればComfyUIへ転送できます。

## 保存と読み込み

保存操作によって対象が異なります。

| 操作                                 | 保存するもの                                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| ギャラリーの保存／Ctrl+S             | 選択中の生成結果を、設定したサーバー側の画像保存先へ保存                                                            |
| ギャラリーのダウンロード             | 選択中の生成結果をブラウザ経由でダウンロード                                                                        |
| Ctrl+Shift+S                         | 現在のワークフローとキャプチャしたサムネイルをComfyUIのワークフロー一覧へ保存。既存なら上書き、未保存なら名前を指定 |
| グローバルメニューのワークフロー出力 | ワークフローのJSONファイル                                                                                          |
| グローバルメニューのレイアウト出力   | ComfyGridのレイアウト設定のみ                                                                                       |
| グローバルメニューの一括出力         | ワークフローとComfyGridレイアウトをまとめたファイル                                                                 |

ComfyGridのレイアウト情報はワークフローのメタ情報にも含まれます。ワークフローと表示配置をまとめて持ち出す場合は、一括出力を使用してください。レイアウト単体のファイルには、ComfyUIのワークフロー全体は含まれません。

**Files → Workflows**では、保存済みワークフローの閲覧やフォルダ・ファイル名の整理ができます。Settingsでは画像の保存先、日付などのサブフォルダ名、ファイル名、保存形式、画質、メタ情報の埋め込みを設定できます。

| ショートカット | 操作                                            |
| -------------- | ----------------------------------------------- |
| Ctrl+Enter     | 生成をキューに追加                              |
| Ctrl+S         | 現在のギャラリー画像を保存                      |
| Ctrl+Shift+S   | 現在のワークフローとサムネイルを保存            |
| Ctrl+O         | JSONファイルからComfyGridのレイアウトを読み込む |

ショートカットはComfyGrid画面側のものです。エディタや内蔵ComfyUIでは、それぞれのショートカット処理が優先される場合があります。

Ctrl+Oは、レイアウト単体または一括出力ファイルのレイアウト部分を復元する操作であり、ワークフローのグラフは読み込みません。ワークフロー自体はComfyUI・Files・ヘッダーへのドロップなどから読み込んでください。

## 設定

言語・テーマ、グループのタブ表示、ノードモードの簡略化、GridStackのグリッド・ドット背景、ギャラリーやモデルサムネイルのサイズ、システムモニター、画像保存、Ollama、PromptPilotなどを設定できます。

ボードの共通化などのレイアウト設定はワークフローごとに保持します。レイアウト出力には対象のComfyGrid表示設定が含まれますが、アプリ全体のグローバル設定とは別のものです。

## 起動オプション

`python main.py`で起動する場合、次のアプリケーション引数を指定できます。

| 引数                 | 説明                                                                                           | 初期値      |
| -------------------- | ---------------------------------------------------------------------------------------------- | ----------- |
| `--host`             | バックエンドAPIの待ち受けアドレス。これだけでCaddy経由の外部公開を設定するものではありません。 | `127.0.0.1` |
| `--port`             | ブラウザからアクセスするリバースプロキシのポート                                               | `6210`      |
| `--server-port`      | バックエンドAPIの内部ポート                                                                    | `8000`      |
| `--log-level`        | `INFO`・`DEBUG`などのログ出力レベル                                                            | `INFO`      |
| `--extension-update` | 起動準備時に、バージョン固定されていない推奨ComfyGrid拡張機能の更新を有効化                    | OFF         |

ComfyUI本体の起動引数は、セットアップのプロファイルで指定してください。`--comfyui-args`はComfyGridの専用コマンドライン引数ではありません。

## 困ったとき

- **起動が完了しない:** ローディング画面とターミナルのログを確認してください。ファイルのダウンロードには時間がかかる場合があります。復帰用ボタンが表示されたらRetryを使うか、セットアップに戻ってパスやポートを確認してください。
- **生成できない:** ComfyUI単体でワークフローが動作するか、必要なモデル・カスタムノードが導入されているか確認してください。
- **追加したモデルが出ない:** モデル一覧を更新し、ComfyUIが参照するモデルフォルダを確認してください。
- **画像を保存できない:** 設定した保存先と書き込み権限を確認してください。サーバー側の保存とブラウザのダウンロードでは保存先が異なります。
- **Ollama翻訳に失敗する:** Ollamaの起動状態、接続先URL、モデルの導入状態を確認し、通知されたエラーの詳細を確認してください。

グローバルメニューのComfyUIリロードは内蔵ComfyUI画面の再読み込み、ComfyUI再起動はPythonプロセスの再起動です。ComfyGrid画面全体のリロードとは異なります。

## 技術構成とクレジット

[Caddy](https://caddyserver.com/)をリバースプロキシとして使用し、ComfyGridとComfyUIをブラウザ側の単一ポートから利用できるようにしています。起動準備時には`custom_nodes/ComfyUI-comfygrid`に連携用拡張を導入し、ワークフローやウィジェットを連携します。

PromptPilotのDanbooruタグ補完はCodeMirrorに統合済みです。以前の`comfygrid-prompt-pilot`拡張を別途導入する必要はありません。[sd-webui-prompt-pilot](https://github.com/nihedon/sd-webui-prompt-pilot)を基にしています。
